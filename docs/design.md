# Codex Pulse UI 설계

## 선택 방향

작업 표시줄의 빈 왼쪽 영역에 실제 시스템 유틸리티처럼 보이는 2×2 정보 매트릭스를 고정한다.

```text
CODEX 72%    CPU 18%
RESET 02:14  MEM 65%
```

## 시각 원칙

- Codex를 가장 먼저 읽히는 주 정보로 둔다.
- CPU와 메모리는 동일한 밀도의 보조 정보로 둔다.
- Segoe UI Variable과 고정 폭 숫자를 사용한다.
- 민트, 앰버, 바이올렛은 작은 상태 표시선과 그래프에만 사용한다.
- 카드 그리드, 큰 제목, 과한 글로우, 장식용 문구를 사용하지 않는다.
- 패널 내부는 행과 가는 구분선으로 구성한다.

## 동작

- 접힌 위젯 클릭: 상세 패널을 작업 표시줄 위로 확장
- 상세 상태에서 접힌 영역 클릭: 원래 크기로 복귀
- 새로고침: Codex 계정 데이터 즉시 다시 읽기
- 닫기: 프로세스 종료가 아닌 시스템 트레이로 숨기기
- 트레이 왼쪽 클릭: 접힌 위젯 다시 표시

## 데이터 신뢰도

- 연결됨: Codex app-server의 실제 계정·한도·토큰 데이터
- 데모: 로그인 또는 연결 실패 사유를 패널 상단에 표시
- 구독 결제일·만료일: 공식 응답에 없으므로 만들거나 추정하지 않음
